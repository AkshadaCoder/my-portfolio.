6. Verify that every project feature listed is implemented and every link works.

USING CODEPEN
- Paste the contents of index.html into the HTML panel.
- Paste style.css into the CSS panel.
- Paste script.js into the JS panel.
- Because CodePen separates the panels, you can leave the stylesheet and script
  references in HTML; CodePen's HTML panel may load them as separate resources,
  so remove the <link rel="stylesheet" href="style.css"> and
  <script src="script.js" defer></script> lines if they cause duplicate loading.
- For a public portfolio website, upload these files to GitHub and enable GitHub Pages.
